# EduLoop AI – Evaluation Rubric

Each criterion is binary: PASS or FAIL. A lesson is approved only when all
10 criteria pass.

| ID | Criterion | Pass condition |
|---|---|---|
| R1 | Accuracy | Technically correct; no material misconception |
| R2 | Grounding | No fabricated statistics, citations or unsupported claims |
| R3 | Beginner-friendly | Understandable to a learner starting from zero |
| R4 | Simple language | Jargon is avoided or explained on first use |
| R5 | What and why | Defines the topic and explains why it matters |
| R6 | How it works | Explains the important stages in logical order |
| R7 | Practical example | Includes a realistic end-to-end example |
| R8 | Teaching flow | Concepts build in a coherent sequence |
| R9 | Standalone | Sufficient context without external material |
| R10 | Learning assessment | Recap and at least five questions with answers |

A single FAIL rejects the draft. The system allows one initial generation and
at most two retries. After the final failed attempt, it stops and marks the
result REJECTED_FOR_HUMAN_REVIEW.
